# Site da ONG Lar do Amor

Projeto de site desenvolvido como atividade de desenvolvimento front-end.

## Como abrir

Abra o arquivo `index.html` no navegador. Para testar os módulos JavaScript, use um servidor local, como o Live Server no VS Code.

## Organização do código

O arquivo `main.js` reúne as funções principais do site. O arquivo `favoritos.js` contém as funções usadas para salvar e recuperar os projetos favoritos no `localStorage`.

## O que foi testado

Testei se os favoritos continuam marcados depois de atualizar a página. Durante o desenvolvimento, também encontrei um problema em que o conteúdo do site deixava de aparecer e fiz ajustes para que voltasse a ser exibido.

## Próximos passos
